# Archivos de ejemplo

Aquí va el archivo Excel real de ventas (decisión **D-03** del documento de producto), aunque
tenga las cifras alteradas.

El importador es el componente más riesgoso del proyecto y no se puede diseñar bien contra un
formato imaginario: hace falta ver los encabezados reales, cómo vienen escritos los nombres de
los clientes, si hay código de cliente, cómo se representa el periodo y qué filas de totales o
subtotales hay que ignorar.

Los archivos `.xlsx` de esta carpeta están excluidos del repositorio en `.gitignore`.
